## ✨ 一句话
**DeepSeekMD** 是一个**单文件 HTML** 的 Markdown 编辑器，你可以在文档里像写普通 Markdown 一样写文章，但又能随时插入 **「单字函数」** 来生成表单、图表、多媒体、游戏甚至音乐，让文档“运行”起来。
---
## 🚀 特性
- 📝 **三合一编辑器**：代码 + 预览 + AI 聊天，实时分屏渲染
- ⚡ **单字函数**：通过 200+ 个内置汉字函数（如 `入`、`密`、`柱`、`饼`、`音`、`玩`），零代码生成 HTML 组件
- 🎵 **汉符音**：用中文数字（一二三四五六七 等）写乐谱，在浏览器里演奏
- 🤖 **AI 扩展**：接入 DeepSeek API，可在聊天中让 AI 帮你写文档、扩展新函数
- 🎨 **丰富可视化**：柱状图、饼图、折线图、雷达图、热力图、漏斗图……全内置
- 📦 **纯前端**：没有任何构建工具，一个 HTML 文件即开即用
- 🌗 **暗色主题**：Ctrl+T 一键切换
- 🔌 **本地存储**：文档自动保存，不怕丢失

## 📖 三种语法（都是合法的）
```markdown
1. 标准式：【入】`姓名,请输入,齐庄`
2. 简略式：入`姓名,请输入,齐庄`
3. 行首式：入 姓名,请输入,齐庄
4. 单字行：雨           ← 直接一个函数名，按行首解析
```
所有函数的第一个参数都是 **元素 ID**，后续参数用逗号分隔。

## 🎵 汉符音（音乐编程）
用五套数字体系控制音高，在文档中直接写旋律：
```
１１５５６６５　４４３３２２１
```
五套音阶：
- 超高：壹贰叁肆伍陆柒
- 高音：一二三四五六七
- 中音：１２３４５６７
- 低音：①②③④⑤⑥⑦
- 超低：㈠㈡㈢㈣㈤㈥㈦
点击“演奏”按钮，浏览器会通过 Web Audio API 播放。

## 🚦 快速开始
### 在线使用
直接访问 [http://deepseekmd.com](http://deepseekmd.com) 即可，无需安装。
### 本地运行
1. 下载本项目中的 `deepseekmd.html`（或直接保存网页）
2. 用浏览器打开该文件
3. 开始编辑和运行！
### 在项目中嵌入
```html
<script src="https://asiide.com/js/asimarkdown.js"></script>
<script>
  const html = asimarkdown(markdownText);  // 将单字语法转为 HTML
</script>
```
这样你就可以在自己页面里渲染 DeepSeekMD 语法的内容。

- **扩展函数**：菜单栏“工具”→“扩展新函数”，写单字函数即时生效
